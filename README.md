# Simple Launcher (Android)

Мінімальний лаунчер на Kotlin: сітка застосунків, пошук, довге натискання → «Про застосунок» / «Видалити».

## Запуск
1. Відкрийте папку в Android Studio (File → Open) і дочекайтесь синхронізації Gradle.
2. Запустіть на пристрої або емуляторі.
3. Натисніть кнопку «Додому» — Android запропонує обрати лаунчер за замовчуванням.
