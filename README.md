# Simple Launcher — стиль iOS 6

- Глянцеві заокруглені іконки з градієнтом, відблиском і тінню.
- Сторінки 4×5 зі свайпом вліво/вправо та крапками внизу.
- Сторінка пошуку (Spotlight) зліва від першої сторінки, на «льняному» фоні.
- Скляний док на 4 застосунки.
- Довге натискання на іконку: додати/прибрати з дока, про застосунок, видалити.
